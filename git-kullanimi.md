# Git Kullanımı

git init: bir git repository'si oluşturur ve bunu sadece lokalde yapar (lokal sadece bu bilgisayar demektir.)

git add .

git commit -m "initial commit"

git remote add origin <repository_urlsi> (github'daki repository ile arada bir bağlantı/köprü oluşturur)

git push -u origin <var_olan_branch_adı>
